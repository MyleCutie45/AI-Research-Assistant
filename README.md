Overview

This project implements a Multi-Agent AI Research Assistant designed to automate and enhance the research workflow.

Instead of relying on a single AI model, the system coordinates several specialized agents that work together:

Planner Agent — breaks research goals into tasks
Search Agent — gathers information from external sources
Summarizer Agent — condenses findings
Critic Agent — verifies quality and detects inconsistencies
Writer Agent — generates polished final reports
Coordinator Agent — manages communication between agents

The architecture enables:

Parallel reasoning
Better factual consistency
Modular extensibility
Human-in-the-loop workflows
Scalable research pipelines
